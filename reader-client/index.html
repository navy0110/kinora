How this client works

This is a standalone static site. It queries the Tiramisu public RPC using Arkiv SDK 0.8.1. It does not call Kinora or use its sample records. Community identifiers are self-declared; creator addresses show authorship, not verified affiliation.

Dependencies are loaded from esm.sh. A CDN or RPC outage can interrupt reads. Events expire; this is not a permanent archive.
Open Agenda is a reference client. All hackathon content must be synthetic.
